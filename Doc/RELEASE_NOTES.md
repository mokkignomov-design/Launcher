# Runia Launcher v1.0.4

## Что нового
- Проверка обновлений больше не задерживает запуск лаунчера дольше двух секунд.
- Если проверка занимает больше времени, она продолжается в фоне; загрузка начинается после показа окна лаунчера.
- Добавлено компактное окно статуса проверки и загрузки, оформленное в активной теме.

## Установка
Скачайте установщик `Runia-win-Setup.exe` из раздела Releases на GitHub.

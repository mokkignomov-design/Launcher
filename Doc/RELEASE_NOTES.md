# Runia Launcher v1.0.0-beta.1 - Release Notes

**Дата релиза:** Январь 2025  
**Версия:** 1.0.0-beta.1  
**Статус:** Beta (Закрытый бета-тест)

---

## 🎉 Что нового

### Основной функционал
- ✅ **Аутентификация через JWT** - поддержка регистрации и входа
- ✅ **Запуск Minecraft** - интеграция с CmlLib для установки и запуска игры
- ✅ **Управление серверами** - список доступных серверов с возможностью подключения
- ✅ **Сск ины** - поддержка загрузки и применения скинов
- ✅ **Новости** - отображение актуальной информации о проекте
- ✅ **Темы** - светлая и темная тема интерфейса
- ✅ **Профиль пользователя** - просмотр данных аккаунта
- ✅ **Параметры** - настройки приложения

### Улучшения
- WPF приложение на .NET 9.0-windows
- Архитектура MVVM + DI Container
- ILogger для логирования
- Обработка ошибок через ApiResult<T>
- Secure token storage для JWT
- Support for auto-login при наличии валидного refresh token

---

## ⚠️ Известные ограничения (Beta)

1. Приложение находится в **закрытом бета-тесте**
2. Минимальная версия .NET Runtime: 9.0+
3. Поддержка только Windows (net9.0-windows)
4. API сервер должен быть доступен по адресу https://api.runia.su/

## 🔧 Требования для установки

- **ОС:** Windows 10/11 64-bit
- **.NET Runtime:** 9.0+
- **Память:** минимум 512 МБ
- **Интернет:** требуется для работы

## 🚀 Установка

1. Скачайте установщик `Runia-Launcher-1.0.0-beta.1.exe`
2. Запустить инсталлятор
3. Выполнить инструкции на экране
4. Запустить приложение из Start Menu или Desktop

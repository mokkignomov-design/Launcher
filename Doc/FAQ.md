## 🎮 Общие вопросы

### Q: Что такое Runia?
**A:** Runia Launcher - это современный лаунчер для Minecraft, разработанный на C# с использованием WPF и .NET 9. Он предоставляет удобный интерфейс для запуска игры, управления модами, проверки статуса серверов и взаимодействия с сообществом.

### Q: На какой платформе работает Runia?
**A:** Runia разработана исключительно для **Windows**. Требуется Windows 7 SP1 или выше. Поддержка Linux/macOS может быть добавлена в будущем с помощью Avalonia.

### Q: Это официальный Minecraft лаунчер?
**A:** Нет, Runia - это сторонний лаунчер. Он использует официальные серверы Minecraft для аутентификации и загрузки игры.

### Q: Безопасно ли использовать Runia?
**A:** Да, Runia использует стандарт JWT для аутентификации и безопасное шифрованное хранилище для сохранения токенов. Ваша информация защищена.

### Q: Стоит ли платить за Runia?
**A:** Runia полностью **бесплатна** и с открытым исходным кодом. Все функции доступны безвозмездно.

## 📦 Установка и запуск

### Q: Какие требования к системе?
**A:** 
- **ОС:** Windows 7 SP1 или выше
- **.NET Runtime:** .NET 9.0 Desktop
- **ОЗУ:** Минимум 2 ГБ
- **Интернет:** Для скачивания игры и компонентов

Рекомендуется Windows 10/11 с 4+ ГБ ОЗУ.

### Q: Где скачать Runia?
**A:** Скачайте последнюю версию здесь: [GitHub Releases](https://github.com/mokkignomov-design/Launcher/releases)

### Q: Требуется ли установка .NET Framework?
**A:** Да, требуется **.NET 9.0 Desktop Runtime**. Научите скачать его [отсюда](https://dotnet.microsoft.com/download/dotnet/9.0).

### Q: Как установить .NET Runtime?
**A:**
1. Перейдите на https://dotnet.microsoft.com/download/dotnet/9.0
2. Скачайте **Desktop Runtime** для Windows
3. Запустите установщик
4. Следуйте инструкциям

### Q: Runia не запускается после установки
**A:** Проверьте:
1. Установлен ли .NET 9.0 Desktop Runtime (`dotnet --version`)
2. Перезагрузитесь после установки .NET
3. Предоставьте доступ в firewall (если требуется)
4. Проверьте логи: `%APPDATA%\Runia\logs\`

### Q: Почему Runia требует интернет при запуске?
**A:** При первом запуске Runia проверяет доступность API сервера для инициализации. После успешной аутентификации можно играть в офлайн режиме.

## 🔐 Аутентификация

### Q: Я забыл пароль
**A:** 
1. На экране входа нажмите "Забыл пароль?"
2. Введите email вашего аккаунта
3. Откройте письмо восстановления из почты
4. Следуйте ссылке и установите новый пароль

### Q: Мой аккаунт заблокирован
**A:** Если ваш аккаунт заблокирован, свяжитесь с поддержкой через [GitHub Issues](https://github.com/mokkignomov-design/Launcher/issues).

### Q: Как включить двухфакторную аутентификацию?
**A:** Перейдите в **Профиль → Безопасность** и включите 2FA там. Вам потребуется приложение-аутентификатор (Google Authenticator, Authy и т.д.).

### Q: Я не получаю письма для подтверждения
**A:** 
1. Проверьте папку "Спам"
2. Убедитесь, что email правильный
3. Запросите повторную отправку письма
4. Проверьте спам-фильтр почтовика

### Q: Токен истёк, что делать?
**A:** Просто переавторизуйтесь:
1. Выйдите из профиля (Профиль → Выход)
2. Введите учётные данные заново
3. Новый токен будет автоматически сохранён

## 🎮 Игра и Minecraft

### Q: Где устанавливается Minecraft?
**A:** По умолчанию в:
```
%APPDATA%\Runia\.minecraft\
```

Вы можете изменить это в **Настройках → Пути**.

### Q: Runia не находит Java
**A:** 
1. Runia автоматически попытается установить Java
2. Если это не сработало, установите Java вручную:
   - Скачайте JDK 8 или 17 с [oracle.com](https://www.oracle.com/java/technologies/downloads/)
   - Установите её
   - Перезагрузитесь

### Q: Какая версия Java нужна?
**A:** 
- Minecraft 1.12 и ниже → Java 8
- Minecraft 1.13-1.16 → Java 8 или 11
- Minecraft 1.17+ → Java 16+

Runia автоматически выберет нужную версию.

### Q: Можно ли запустить несколько экземпляров игры одновременно?
**A:** По умолчанию нет. Если вы хотите мультиплеер, присоединитесь к серверу через Runia.

### Q: Почему игра запускается долго?
**A:** 
1. **Первый запуск** - загружаются все файлы (может быть 10+ минут)
2. **Медленный интернет** - увеличивает время загрузки
3. **Медленный диск** - используйте SSD если возможно
4. **Память** - недостаточно ОЗУ может замедлить запуск

### Q: Как увеличить выделяемую памсть для игры?
**A:** В **Настройках → Игра** найдите параметр `Java Memory` и установите нужное значение (в МБ).

### Q: Runia вылетает при запуске игры
**A:**
1. Проверьте логи: `%APPDATA%\Runia\logs\`
2. Обновите драйверы видеокарты
3. Попробуйте запустить на меньших настройках графики
4. Убедитесь, что свободно достаточно места на диске

## 🖥️ Серверы

### Q: Как присоединиться к серверу через Runia?
**A:** 
1. Перейдите в **Серверы** в главном меню
2. Выберите желаемый сервер
3. Нажмите **Присоединиться**
4. Runia откроет игру с правильными параметрами подключения

### Q: Я вижу сервера, но не могу присоединиться
**A:** 
1. Проверьте интернет-соединение
2. Сервер может быть офлайн (проверьте статус)
3. Проверьте firewall - может блокировать доступ
4. Убедитесь, что у вас есть доступ на сервер

### Q: Как добавить свой сервер в список Runia?
**A:** Свяжитесь с администрацией и заполните форму добавления сервера в [GitHub](https://github.com/mokkignomov-design/Launcher/issues/new).

### Q: Почему я вижу "0 игроков" на сервере?
**A:** 
1. Сервер может быть офлайн
2. Данные о количестве игроков могут быть устарелыми
3. Сервер хостится не на официальных серверах Mojang

### Q: Могу ли я запустить локальный сервер через Runia запустить локальный сервер через Runia?
**A:** Runia прежде всего лаунчер. Для хостинга сервера используйте [server.jar](https://launcher.mojang.com/v1/objects/3dc3d84a581f14691199be2bfbf4dd4ce03b7691/server.jar).

## 👤 Профиль и скины

### Q: Как загрузить пользовательский скин?
**A:**
1. Перейдите **Профиль → Скин**
2. Нажмите **Загрузить скин**
3. Выберите PNG файл размером 64×64 пиксела
4. Нажмите **Сохранить**

### Q: Какой размер и формат скина?
**A:** 
- **Размер:** 64×64 пиксела
- **Формат:** PNG
- **Прозрачность:** поддерживается

### Q: Мой скин не отображается
**A:**
1. Проверьте размер (должен быть ровно 64×64)
2. Убедитесь что это PNG файл
3. Попробуйте загрузить снова
4. Проверьте интернет-соединение

### Q: Где хранятся скины?
**A:** Скины хранятся на сервере Runia и синхронизируются автоматически.

### Q: Могу ли я вернуть стандартный скин?
**A:** Да, в **Профиль → Скин** найдите опцию "Использовать стандартный скин".

### Q: Как посмотреть историю загруженных скинов?
**A:** Сейчас это не поддерживается, но планируется добавить в будущих версиях.

## 🔧 Проблемы и лагирование

### Q: Игра лагирует / низкий FPS
**A:**
1. Уменьшите настройки графики в меню игры
2. Выделите больше памяти Java: **Настройки → Игра → Memory**
3. Закройте другие приложения
4. Обновите драйверы видеокарты

### Q: "Ошибка 401 Unauthorized"
**A:** Ваш токен истёк или недействителен:
1. Выйдите из профиля
2. Переавторизуйтесь
3. Токен будет обновлён автоматически

### Q: "Ошибка подключения к API"
**A:**
1. Проверьте интернет-соединение
2. Проверьте, доступен ли сайт: https://api.runia.su/
3. Проверьте firewall и антивирус (могут блокировать)
4. Попробуйте позже (может быть апдейт сервера)

### Q: Runia использует много памяти
**A:** 
1. Закройте ненужные приложения
2. Проверьте, нет ли утечки памяти (посмотрите в Task Manager)
3. Перезагрузитесь
4. Если проблема продолжается, сообщите о баге

### Q: Скорость загрузки модов очень медленная
**A:**
1. Это нормально при первой установке больших модпаков
2. Проверьте скорость интернета (speedtest.net)
3. Убедитесь, что другие приложения не используют интернет
4. Попробуйте подключиться к другой сети

### Q: Runia вылетает при клике на определённую кнопку
**A:**
1. Проверьте логи: `%APPDATA%\Runia\logs\runia_YYYY-MM-DD.log`
2. Опубликуйте лог в [GitHub Issues](https://github.com/mokkignomov-design/Launcher/issues)
3. Включите краткое описание проблемы

### Q: Как очистить кеш приложения?
**A:**
```powershell
# Удалить кеш изображений
Remove-Item -Path "$env:APPDATA\Runia\cache\images\*" -Force

# Удалить логи
Remove-Item -Path "$env:APPDATA\Runia\logs\*" -Force

# Удалить временные файлы
Remove-Item -Path "$env:APPDATA\Runia\temp\*" -Force
```

## 👨‍💻 Разработка

### Q: Могу ли я berkutcontribute в проект?
**A:** Да! Runia - проект с открытым исходным кодом. Смотрите [CONTRIBUTING.md](./CONTRIBUTING.md) для инструкций.

### Q: Как собрать Runia из исходного кода?
**A:**
```bash
# Клонировать репозиторий
git clone https://github.com/mokkignomov-design/Launcher.git
cd Launcher

# Восстановить зависимости
dotnet restore

# Собрать
dotnet build

# Запустить
dotnet run --project Runia/Runia.csproj
```

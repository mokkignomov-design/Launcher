## Установка за 5 Минут

### Вариант 1: Использование Готовой Сборки

1. **Скачайте последний релиз**
   ```
   https://github.com/yuranaumov2007-boop/GoGoGaGA/releases
   ```

2. **Распакуйте архив**
   ```
   C:\Program Files\Runia\
   ```

3. **Запустите Runia.exe**
   ```
   Runia.exe
   ```

### Вариант 2: Сборка из Исходного Кода

```powershell
# 1. Клонируйте репозиторий
git clone https://github.com/yuranaumov2007-boop/GoGoGaGA.git
cd GoGoGaGA

# 2. Восстановите зависимости
dotnet restore

# 3. Соберите проект
dotnet build --configuration Release

# 4. Запустите
dotnet run --project Runia/Runia.csproj
```

## Первый Запуск

### Этап 1: Создание Аккаунта

1. **Откроется окно входа**
2. **Нажмите "Register"**
3. **Заполните форму:**
   - **Username** - ваше игровое имя (3-20 символов)
   - **Email** - адрес для восстановления пароля
   - **Password** - надежный пароль (минимум 8 символов)

4. **Проверьте Email**
   - Вам придет письмо с кодом подтверждения
   - Введите код в приложении

5. **Готово!**
   - Теперь вы можете войти в приложение

### Этап 2: Настройка Профиля

1. **Перейдите в Settings (иконка шестеренки)**
2. **Настройте основные параметры:**
   - **RAM** - выберите объем памяти для игры (рекомендуется 4-8 GB)
   - **Game Path** - путь для установки серверов (по умолчанию OK)
   - **Theme** - выберите светлую или темную тему

3. **Нажмите Save**

### Этап 3: Первый Запуск Игры

1. **Перейдите на вкладку Servers**
2. **Выберите интересующий вас сервер**
3. **Нажмите "Play"**
4. **Ожидайте:**
   - Установка Java (первый раз, затем используется кэш)
   - Установка Forge
   - Скачивание модпака
   - Запуск игры

## Основные Действия

### Запуск Игры на Сервере

```
1. Servers (левая панель) → выберите сервер → Play
2. Ожидайте установки компонентов
3. Игра запустится автоматически
```

**Что происходит в фоне:**
- Проверка Java Runtime
- Установка Forge Modloader
- Скачивание и распаковка модов
- Запуск Minecraft с вашим аккаунтом

### Просмотр Новостей

```
1. Home (левая панель) - показывает последние новости
2. Нажимайте на новость для полного просмотра
```

### Изменение Настроек

```
1. Settings (левая панель) → иконка шестеренки
2. Измените нужные параметры
3. Нажмите Save
```

### Выход из Аккаунта

```
1. Нажмите на ваше имя в левом нижнем углу
2. Выберите Logout
3. Вернетесь на экран входа
```

## Быстрые Ответы на Популярные Вопросы

### Q: Игра не запускается, что делать?
**A:** Посмотрите [Решение Проблем](./TROUBLESHOOTING.md#игра-не-запускается)

### Q: Как изменить объем RAM?
**A:** Settings → RAM slider → Save (смотрите [Настройка Приложения](./SETTINGS_GUIDE.md))

### Q: Забыл пароль, как восстановить?
**A:** На экране входа нажмите "Forgot Password?" и следуйте инструкциям

### Q: Где мои сохранения игры?
**A:** Сохранения хранятся в `%APPDATA%\Runia\versions\[ServerName]\.minecraft\saves\`

### Q: Как добавить новый сервер?
**A:** Смотрите [Управление Серверами](./SERVER_MANAGEMENT.md)

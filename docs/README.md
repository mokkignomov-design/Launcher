# Runia - Документация

**Runia** — это WPF-приложение на .NET 9, предназначенное для управления игровыми серверами и контентом. Приложение реализует функционал аутентификации, регистрации, авторизации и управления аккаунтом.

## ✅ Текущие возможности

- ✅ **Аутентификация**: Регистрация, вход, сброс пароля
- ✅ **Подтверждение email**: Верификация через код подтверждения
- ✅ **JWT токены**: Безопасное хранилище токенов
- ✅ **Тематизация**: Тёмная и светлая темы
- ✅ **Навигация**: MVVM паттерн с полной поддержкой навигации
- ✅ **Управление установками**: Forge, Java, модпаки

## 🔧 Технический стек

- **Язык**: C# 12
- **Framework**: .NET 9 (WPF)
- **Паттерны**: MVVM, DI, Async/Await
- **Коммуникация**: HTTP REST API с JWT аутентификацией
- **UI Framework**: WPF с XAML

## 📦 Основная структура проекта

```
Runia/
├── Ui/                          # Интерфейс пользователя
│   ├── Pages/
│   │   ├── Auth/               # Страницы аутентификации
│   │   ├── Main/               # Основные страницы
│   │   └── Controls/           # Переиспользуемые компоненты
│   └── Windows/                # Главные окна приложения
├── ViewModels/                 # Логика представления (MVVM)
│   ├── Auth/                   # ViewModels для аутентификации
│   ├── Main/                   # ViewModels для основного функционала
│   └── Windows/                # ViewModels для окон
├── Services/                   # Бизнес-логика
│   ├── Auth/                   # Сервисы аутентификации
│   ├── Common/                 # Общие сервисы
│   └── Core/
│       ├── Infrastructure/     # API, конфигурация, хранилище
│       ├── Navigation/         # Система навигации
│       └── Launcher/           # Управление версиями
├── assets/                     # Ресурсы (иконки, шрифты, темы)
└── Properties/                 # Свойства проекта
```

## 📝 Примечания для разработчиков

- Проект использует **C# 12 collection expressions** для инициализации коллекций
- Используется **MVVM Community Toolkit** для упрощения MVVM паттерна
- **Dependency Injection** настраивается в `App.xaml.cs` через Microsoft.Extensions
- API интеграция построена на **HttpClient** с кастомным **JwtHandler**

## ❓ Часто задаваемые вопросы

**В:** Как запустить приложение?
**О:** См. [Начало работы](./GETTING_STARTED.md)

**В:** Где хранятся токены?
**О:** Токены хранятся безопасно через `SecureTokenStore`. Подробнее: [Сетевое взаимодействие](./NETWORK.md)

**В:** Как добавить новый API эндпоинт?
**О:** Используйте `BaseApiService`. Подробнее: [API для разработчиков](./API_REFERENCE.md)

**В:** Что делать, если я хочу изменить API URL?
**О:** Измените значение в `DefaultAppConfig`. Подробнее: [Сервисы](./SERVICES.md)
